# worldofduchame.com

The landing page for **World of Duchame & The Dark Tide**, a free browser RPG built from a 1988 D&D binder.

**Play it:** https://michaelwickerson.itch.io/world-of-duchame

This repository only holds the website, served by GitHub Pages at https://www.worldofduchame.com.
The page's source of truth is the `site/` folder of the game's own (private) repository; copy it here to update.
